Self-hosted file sharing server: **Web UI + SFTP + FTP** with one shared virtual filesystem.

Share folders from any drive over your LAN or the internet: public download links (with optional password and expiry), one-click ZIP download of folders, and classic SFTP/FTP access for file management.
